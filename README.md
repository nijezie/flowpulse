## 🔧 **API Endpoints:**

- `GET /api/health` - Health check
- `GET /api/flows` - Recent stablecoin flows
- `GET /api/flows/heatmap` - Heatmap data
- `GET /api/flows/timeseries` - Time-series data
- `GET /api/alerts` - Alert management
- `POST /api/alerts` - Create new alerts
- `GET /api/bets` - Betting history
- `POST /api/bets` - Place new bets
- `GET /api/bets/odds` - Current odds
